          Sentinel. Read tools (open pages, read text, list vault labels) run
          directly. Routine browser clicks, typing, and key presses are auto-approved
          by default. vault_fill always needs approval and is domain-bound.
          Other write tools need approval unless you turn on auto-approve.
          Shell commands are off by default. Normal workspace commands and
          GET/wget/curl reads run directly; install commands, unsafe paths, and
          non-GET downloads need approval, then are remembered so you do not
          approve the same command again. Approving one curl
          command trusts all later curl variations. /tmp,
          ~, and /dev/null are scratch paths.
